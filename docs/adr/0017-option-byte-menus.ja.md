# ADR-0017: option bytes のメニュー

- Status: Accepted

## 決定

option bytes の USER の項目のうち、スケッチの動きを決めるものをボードメニューにする。

1. **メニューの先頭は工場出荷の値で、何も組み込まない。** チップはそのときの設定のままで、費用は 0。もう一方の項目を選んだときだけ、起動時にコアが USER を比べ、違えば一度だけ書き換えてリセットする（`ch32rv_option_user.c`）。ch32rv などで変えても、その項目で作ったスケッチが動くたびに戻る。
2. **保護はメニューにしない。** RDPR（読み出し保護）と WRPR（書き込み保護）は、解くとフラッシュが消えるか、書き込みの道具が届かなくなる。ch32rv の `target option` で扱う。
3. **DATA0 / DATA1 はメニューにしない。** 利用者のデータで、版や板ごとに決める値ではない。
4. **起動の経路（ブートローダーに入る条件）はメニューにしない。** ch32rv の書き込みと ISP が扱う。
5. **コアの機能が工場出荷の値に頼る項目は、メニューにしない。** 変えるとコアの API の約束が崩れる。

## 項目ごとの扱い（ch32-device-data の option_byte_fields.csv、12 家系）

| USER の項目 | 家系 | 扱い | 理由 |
|---|---|---|---|
| RST_MODE、CFGRSTEN | V00x、M030、X035（X033）、X315（X305） | **メニュー（Reset Pin、済み）** | 規則 1 |
| RAM_CODE_MOD | V20x、V30x、V407 | **メニュー（Flash / RAM Split）**。済みは V303、V305、V307、V317。V20x（V208）と V407 は候補 | 規則 1。リンカーの配置も一緒に変わる |
| IWDGSW、IWDG_SW | M030 以外の 11 家系 | **メニュー（Watchdog）**。済みは書き換えを実機で通した家系（V00x、M007、X03x、X3x5、V30x、V20x、V205、L103 / M103、V407 / V467）。V103 と H41x は、書き換えを実機で通してから | 規則 1。電源投入直後から止まらない WDT は、製品の暴走対策で使う（V307、V203、L103、V205、V407 で、書き換えと戻しを確かめた） |
| RST_PIN_SEL | M030 | **メニューの候補**（どの端子をリセットにするか） | 規則 1 |
| OV_CFG | M030 | **調べてから決める** | 過電圧の扱い。RM の記述を確かめていない |
| PORCTR | V103 | **調べてから決める** | 電源投入のリセットの時間 |
| STANDYRST、STOPRST | 10 家系 | **扱わない** | 規則 5。`CH32RV.deepSleep()` と `lightSleep()` は、休止に入ってもリセットしない工場出荷の値に頼る |
| CFGCANM | L103、V205 | **扱わない** | CAN のライブラリが無い。できたら、そのライブラリの設定にする |
| START_MODE、START_MD | V003、V006、X315 | **扱わない（ch32rv）** | 規則 4 |
| USARTDLEN、USBFSDLEN、USBHSDLEN | H417、X315 | **扱わない（ch32rv）** | 規則 4 |
| RDPR、WRPR | 全家系 | **扱わない（ch32rv）** | 規則 2 |
| Data0 / Data1 | 全家系 | **扱わない** | 規則 3 |

## 理由

- 先頭を工場出荷の値にすると、メニューに触れない利用者は何も払わず、チップも変わらない。選んだ利用者だけが、起動の比べと 1 回の書き換えを払う（Reset Pin では V003 で 276 B）。
- メニューは自動生成なので、項目を足す費用は小さい。後から減らすのも楽なので、選べる形を先に用意する。

## 実装

- 起動時の比べと書き換え: `cores/arduino/ch32rv_option_user.c`（crt0 から呼ぶ）。
- メニューの生成: `tools/generate/generate.py`（`RSTPIN`、`RAMSPLIT_MENU`）。
