# ファイルシステム(要件と比較の計画)

2026-10-21 に着手。**まだ何も採用していない。** 候補を同じ物差しで測ってから選ぶ。
ESP32 は FAT / SPIFFS / LittleFS を並べて選べる形なので、1 つに絞ることも前提にしない。

## 使い道

| 使い道 | 媒体 | PC と同じ形式が要るか | 主に効く性質 |
|---|---|---|---|
| HTTP の設定サーバー(設定の JSON、Web の静的ファイル) | 内蔵 Flash、SPI の NOR Flash | 要らない | 電源断への強さ、摩耗の分散、小さいファイルの多さ |
| センサーノードのログ | SD カード | 要る(PC で読む) | 追記の速さ、電源断で失う範囲 |
| USB MSC デバイスで見せる SD をスケッチからも読む | SD カード | 要る | FAT。PC が触っている間の排他 |
| USB MSC ホスト(`mscMount()`、USB メモリ) | USB メモリ | 要る | FAT32、exFAT |
| UF2 での更新 | — | — | FS は要らない(仮想の FAT を見せるだけ) |

## 必須と「できるか見るだけ」

- 必須
  - FAT の読み書き(SD、MSC ホスト)。ディレクトリ、長いファイル名(英数字)。
  - Flash 向けで電源断に強い FS を、少なくとも 1 つ。
  - 共通のブロックデバイスの口(SD、MSC デバイス / ホスト、RAM ディスク、NOR Flash)の上に載ること。
  - 使わないスケッチには費用がかからないこと(ライブラリとして分ける)。
  - API は ESP32 の `FS` / `File`(`SD`、`LittleFS`、`FFat`)に合わせる。名前の付け方は Network と同じ方針(ESP 名の別名ヘッダーは置かない)。
- できるか見るだけ
  - exFAT(64 GB 以上の SDXC、大きい USB メモリ)。
  - 日本語のファイル名(FatFs のコードページ 932 は表が大きい)。
  - X035 クラス(Flash 62 KB)に FAT を載せること。

## 候補

ライセンスで使えないもの(GPL・LGPL・商用)は最初から外した。

| 候補 | 版 | ライセンス | 形式 | 言語 |
|---|---|---|---|---|
| FatFs | R0.16 | 1 条項 BSD 相当 | FAT12/16/32、exFAT | C |
| Petit FatFs | R0.03a | 同上 | FAT(読み出しと限られた書き込み) | C |
| SdFat | 2.3.1 | MIT | FAT16/32、exFAT | C++ |
| littlefs | 2.11.3 | BSD-3 | 独自(Flash 向け、電源断に強い) | C |
| SPIFFS | 0.3.7(上流の更新は少ない) | MIT | 独自(Flash 向け、ディレクトリなし) | C |

## 物差し

全候補を同じ処理(同じブロックデバイス、同じ手順)で測る。

1. **大きさ**: X035 と V307 で、Flash と RAM(静的、ヒープ、スタックの最大)を測る。機能の段(読み出しのみ、読み書き、長いファイル名、exFAT)ごとに測る。
2. **速さ**: チップの上の RAM ディスクで、FS 自体が使う CPU の時間を測る。
   - 16 KB の書き込みと読み出し。
   - 小さいファイル 20 個の作成。
   - 32 バイトの記録を 1000 回、毎回 sync して追記する。
   - SD での実測は、ベンチに SD を付けてから行う。
3. **電源断**: PC の上で、ブロックデバイスへの書き込みを n 回目で止め、再びマウントする。手順の中のすべての n で調べる。
   - マウントできるか。
   - sync 済みのデータが残っているか。
   - ほかのファイルが壊れていないか。
   - 失うのはどの範囲か。
   - 書きかけのセクタ(半分だけ書けた状態)も試す。
4. **NOR Flash での摩耗**: 消去 4 KB、書き込みは 1→0 だけ、という NOR を模して測る。
   - 同じ処理での消去回数と、その偏り。
   - FAT を NOR に載せる場合は、摩耗分散の層(FTL)が別に要る。この費用も数える。
5. **機能**: ディレクトリ、長いファイル名、タイムスタンプ、同時に開けるファイルの数、空き容量の取得、フォーマット。

## 測った結果(2026-10-21)

計測の仕組み(模擬の媒体、共通の作業、PC の電源断試験、チップのスケッチ)は、まだ作業用の場所にある。候補のソースは上流の版をそのまま使った。

作業の中身(全候補で同じ):
- 設定ファイル 300 B を作り、10 回書き換える。
- Web のファイル 2 つ(2000 B / 4000 B)を書く。
- ログに 32 B を 100 回追記する(毎回 close)。
- 16 KB のファイルを書いて読む(チップでは 4 KB)。
- 64 B の小さいファイルを 20 個作る。

### 大きさ(LTO 既定、FS を入れたときの増分)

| 候補・段 | X035 Flash | V307 Flash | RAM |
|---|---|---|---|
| Petit FatFs(読み出し、既存ファイルへの書き込み) | +1.6 KB | +1.6 KB | +0.6 KB |
| FatFs 読み出しのみ | +2.7 KB | +2.6 KB | +0.6 KB |
| FatFs 読み書き、8.3 形式の名前 | +6.7 KB | +6.6 KB | +0.6 KB |
| FatFs 読み書き、長いファイル名(コードページ 437) | +9.5 KB | +9.5 KB | +0.7 KB |
| 同上 + フォーマット | +10.4 KB | +10.4 KB | +1.2 KB |
| 同上 + exFAT | +16.5 KB | +16.5 KB | +1.4 KB |
| FatFs 長いファイル名、コードページ 932(日本語) | 入らない(13 KB 超過) | +68.5 KB | +0.7 KB |
| SdFat FAT(長いファイル名あり) | +9.4 KB ※ | +9.7 KB | +1.1 KB |
| SdFat FAT + exFAT | +15.7 KB ※ | +16.0 KB | +1.2 KB |
| littlefs | +16.0 KB | +16.1 KB | +1.8 KB |
| SPIFFS | +16.6 KB | +16.6 KB | +2.0 KB |
| SPIFFS(マウントのたびに SPIFFS_check) | +21.3 KB | +21.3 KB | +2.0 KB |

- ※ SdFat は `SdFat.h` の既定引数で `SS` を直接使う。X035 / X033 のバリアントには `SS` が無い(device-data に NSS の pad が無い)ので、そのままではコンパイルできない。計測では `SS` を外から与えた。
- RAM は、計測用の接続部で決めたバッファを含む(littlefs のキャッシュ 3 つ、SPIFFS の作業域・fd・キャッシュ)。設定で増減する。
- スタックの最大(V307 で実測): FatFs 1008 B(FF_FS_TINY で 592 B)、SdFat 640 B、littlefs 1184〜1216 B、SPIFFS 896 B。

### 電源断(PC 上、書き込みのすべての回で切る)

「失う」は、書き終えて close したデータが消えたか、別の中身になったこと。「壊れる」は、マウントはできるが新しいファイルを書けないこと。

| 候補 | 媒体 | 切った回数 | 失う | 壊れる | 失うもの |
|---|---|---|---|---|---|
| FatFs | 16 MB の SD 相当 | 404 | 40 | 0 | 書き換え中の設定ファイル(切り詰めてから書くため、旧も新も無い) |
| FatFs、一時ファイル + リネーム | 同上 | 424 | 20 | 0 | 設定ファイルが無い瞬間(FAT は置き換えのリネームができず、先に消す) |
| SdFat | 同上 | 426 | 0(半分書けたセクタで 1) | 0 | ※ |
| SdFat、一時ファイル + リネーム | 同上 | 486 | 20 | 0 | FatFs と同じ |
| littlefs | NOR 256 KB | 1056 | 0 | 0 | — |
| littlefs | 16 MB の SD 相当 | 326 | 0 | 0 | — |
| SPIFFS | NOR 256 KB | 1204 | 130 | 109 | 設定ファイル。追記中に切ると以後書けなくなる |
| SPIFFS、マウント時に SPIFFS_check | 同上 | 1204 | 239 | 0 | 書けなくはならないが、check がログを消す |

- 追記のログは、FAT でも close 済みの記録を失わなかった。
- ※ SdFat は、切り詰めとディレクトリの更新を close まで遅らせる。そのため、同じ大きさの書き換えなら旧か新のどちらかが残った。大きさが変わる書き換えまでは試していない。
- 半分だけ書けたセクタ / ページ / 消去でも、結果はほぼ同じだった。

### NOR での摩耗(PC 上、64 KB = 16 ブロック)

300 B の静的ファイル 20 個を置き、設定の書き換え(300 B)とログの追記(32 B)を 2000 回繰り返した。

| 候補 | 失敗 | 消去の回数(最少 / 平均 / 最多) | 書いた量 |
|---|---|---|---|
| SPIFFS | 0 | 64 / 65 / 66 | 4.2 MB |
| littlefs(キャッシュ 512 B) | 0 | 0 / 131 / 292 | 4.9 MB |
| littlefs(キャッシュ 256 B) | 300 B のファイル 20 個が 64 KB に入らない | — | — |

- littlefs は、キャッシュ(インライン)より大きいファイルに、1 つで消去ブロック 1 個(4 KB)を使う。小さいファイルが多いと容量を食う。
- littlefs は静的なファイルのブロックを動かさない(block_cycles 500)ので、摩耗が偏る。消去の総数も SPIFFS の 2 倍。
- FAT を NOR に載せるには、摩耗分散の層が別に要る(まだ測っていない)。

### 速さ(V307 96 MHz、RAM の媒体、作業 1 回)

模擬の媒体にかかった時間(実測した 1 回あたりの時間 × 回数)を差し引いた、FS 自体の CPU 時間。

| 候補 | 媒体 | 全体 | うち FS の CPU | ログ追記 1 回 | 書いた量 / 読んだ量 | 消去 |
|---|---|---|---|---|---|---|
| FatFs(長いファイル名) | 16 MB の SD 相当 | 17.5 ms | 約 7 ms | 82 µs | 190 KB / 166 KB | — |
| FatFs(FF_FS_TINY) | 同上 | 15.9 ms | 約 5 ms | 72 µs | 190 KB / 197 KB | — |
| SdFat | 同上 | 16.6 ms | 約 5 ms | 76 µs | 201 KB / 199 KB | — |
| littlefs | 32 KB のブロックデバイス | 280 ms | 約 272 ms | 1.7 ms | 151 KB / 550 KB | — |
| littlefs(キャッシュ 512 B) | NOR 40 KB | 811 ms | 約 769 ms | 7.4 ms | 179 KB / 1010 KB | 92 回 |
| SPIFFS | NOR 40 KB | 119 ms | 約 76 ms | 158 µs | 210 KB / 667 KB | 48 回 |

- littlefs の CPU 時間の多くは、ログの追記と小さいファイルの作成にかかった。媒体が小さい(40 KB)ほど、メタデータの詰め直しが増える。PC 上の 256 KB では、読む回数は 3 割ほど少なかった。
- 本物の NOR では、消去が 1 回 約 45 ms(W25Q の代表値)なので、消去の回数が効く。littlefs 92 回で約 4 秒、SPIFFS 48 回で約 2 秒。
- SPIFFS は既定の設定のままだと、V307 で境界のずれた 2 バイトのストアで止まった(mcause 6、`spiffs_object_append`)。`SPIFFS_ALIGNED_OBJECT_INDEX_TABLES 1` で直った。
- SD での実測は、ベンチに SD を付けてから行う。

### ここから言えること

- FAT(SD、USB メモリ、MSC)は、FatFs と SdFat で大きさ・速さ・電源断の性質がほぼ同じ。違いは次の点。
  - API: SdFat は Arduino 向けの C++ で、`File` に近い。FatFs は C で、口を自分で作る。
  - X035 でのビルド: SdFat は `SS` が要る。
  - 段の細かさ: FatFs は読み出しのみ(+2.7 KB)から段階的に削れる。
  - 日本語のファイル名: FatFs はコードページ 932 で +68.5 KB。
- Flash 向けでは、電源断に強いのは littlefs だけだった。代わりに、CPU 時間、消去の回数、小さいファイルの容量、摩耗の偏りで SPIFFS に負ける。SPIFFS は電源断で書けなくなり、check を入れるとデータを失う。
- X035(Flash 62 KB)には、FAT(読み書き、長いファイル名)で +9.5 KB、読み出しだけなら +2.7 KB で入る。
