# 系列ごとの対応状況

文書基準日: 2026-10-01

ボードメニューには全系列が同じ形で並びます(`Generic <SERIES>`)。どこまで確かめたかは
ボード名ではなくこの表に書きます。ボード名に状態を入れると、確かめるたびに名前が変わるためです。

| 状態 | 意味 |
|---|---|
| **実機で確認** | ベンチ(`tests/benches/`)のジグで、この core のテストを実機に流している |
| **書き込み可・未確認** | 同梱の ch32rv がチップを知っているので書き込める。この core を実機で動かした記録はまだ無い |
| **ビルドのみ** | 同梱の ch32rv がまだチップを知らない。ビルドはでき、書き込みは ch32rv が `target-not-in-db`(exit 20)で probe を開く前に止める。ch32rv が対応した版を同梱すると書き込めるようになる |

どの系列もビルドは CI の compile matrix で全型番を確かめています。
