# SerialHalfDuplex

[English](README.md)

1 線の半二重です。`Serial1` が TX の端子だけ（開放ドレイン）で送受信します。サーボのバスや一部のセンサーの形です。
ボードは 1 秒ごとに `ping` を送り、線に届いたほかのものを出します。

## 必要なものと配線

相手のデータ線 1 本を `Serial1` の既定の TX の端子（`CH32RV_SERIAL2_TX`、USART2 のもの。多くのボードで Serial1）へ、
その線から 3.3 V へプルアップの抵抗（4.7〜10 kΩ）、GND 共通。答えは `Serial`（115200）に出ます。

## 操作と期待する結果

ボードが `One-wire ready` を出し、1 秒ごとに `ping` を送ります。答えが `Serial` に出ます。
プルアップが無いと開放ドレインの線は High に戻らず、送ることも受けることもできません。

## API と処理の流れ

`Serial1.begin(9600, SERIAL_8N1, WIRE_PIN, WIRE_PIN)`（RX と TX に同じ端子、ESP32 の one-wire の形）で、その端子を TX に
持つ route の USART を 1 線のモード（HDSEL）にします。`setPins(p, p)` も同じです。受信器は中で線につながりますが、送った
ものは自分の受信バッファには入りません（USART は送信中に受信しない。ESP32 の one-wire との違い）。読むのは相手の答えだけです。

## 改造するとき

CH32X033 / X035 の端子には開放ドレインが無いので、プッシュプルのまま待機中も線を High に駆動します。ほかに線を駆動する
相手と共有しないでください。速さと問い合わせは相手に合わせます。
