# RtcAlarm

[English](README.md)

暦としてのRTC、そのアラーム、アラームまでの休止、起動を数えるバックアップレジスタを示します。必要なのはUART接続だけです。RTCの無いチップ（V003・V00x・M030・X033/X035）では、その旨を表示し、電源投入からの時刻だけを表示します。

## 操作

1. ターミナルを開いてボードをリセットします。リセット理由、起床の理由、バックアップレジスタ0の起動の回数（リセットのたびに1増える）を表示します。
2. 電源を切ったあとのRTCは1970から始まるので、そのときは2026-01-01に合わせます。日時を表示し、10秒ごとに`Alarm at`と日時を表示します。
3. `s`を送ると、次のアラームまで眠り（`enableAlarmWakeup()`、`lightSleep()`）、結果と起床の理由（3、`CH32RVWakeupCause::Alarm`）を表示します。

## APIと改造時の注意

暦はarduino-esp32と同じPOSIXの時刻です: `time()`、`localtime_r()`、`strftime()`、`mktime()`、`settimeofday()`（SNTPの`configTime()`でも合う）。`CH32RV.setAlarm(when, callback)`は`time()`の秒か、地方時の`struct tm`を取ります。コールバックは割込みの中で1回、時刻のあと1秒以内に呼ばれます（RTCは秒で数える）。ここでは印を付けるだけにし、次のアラームは`loop()`で設定します。アラームは1つで、`setAlarm()`を呼び直すと置き換わります。

RTCは内蔵のLSIで動き、最初の起動でコアがその速さを測ります。1日に数秒〜のずれを見込んでください。バックアップレジスタは16ビットの語（`backupRegisterCount()`個）で、H41xとX305/X315ではリセットでだけ残るRAMです。`enableAlarmWakeup()`と`deepSleep()`は、スタンバイのある系列ではスタンバイで眠り、`setup()`から始まります。そのときコールバックは呼ばれず、`wakeupCause()`がアラームで起きたことを返します。

## 実行前の準備

ボードと正確なPart Numberを選びます。ログはハードウェア`Serial`の115200 baud・8N1です。アダプタRXをボードTX、アダプタTXをボードRXへ接続し、GNDを共通にします。I/O電圧を合わせてください。SWDでつないだデバッガは、眠っている間にチップを見失うことがあります。

生成された`sketch.yaml`にビルドprofileがあります。ビルド成功は配線や実機動作の確認とは別です。[ビルド規則](../../../../../docs/examples-build-rules.ja.md)と[書き込み経路](../../../../../docs/upload-routes.ja.md)も参照してください。
