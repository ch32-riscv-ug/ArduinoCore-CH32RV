# AnalogRead

[English](README.md)

アナログ入力の生値を UART で観察します。

## 必要なものと配線

可変抵抗の両端を入力範囲に合う電源と GND、中央を `SENSOR`（例では `A1`）へ接続します。UART モニタも用意します。

## 操作と期待する結果

可変抵抗を回し、生値が連続的に変わることを確認します。入力を開放すると値が揺れるため、電圧を与えた状態でも確かめます。

## API と処理の流れ

`analogRead(pin)` は設定された分解能の整数値を返します。`analogReadResolution(bits)` は返す数値の幅を指定します。アナログ端子の別名は variant に依存します。

## 改造するときの注意

この例の電圧表示はラベルどおり12 bit・3.3 Vを仮定した計算です。実際の設定に合わせるには、読み出す前に `analogReadResolution(12)` を指定するか、設定した bit 数の最大値に分母を合わせます。電源電圧も確認し、表示だけを精密な電圧測定とは見なしません。
