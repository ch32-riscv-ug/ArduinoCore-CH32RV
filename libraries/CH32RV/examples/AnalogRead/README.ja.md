# AnalogRead

[English](README.md)

アナログ入力の生値と mV 単位の電圧を UART で観察します。

## 必要なものと配線

可変抵抗の両端を入力範囲に合う電源と GND、中央を `SENSOR`（例では `A1`）へ接続します。UART モニタも用意します。

## 操作と期待する結果

可変抵抗を回し、生値が連続的に変わることを確認します。入力を開放すると値が揺れるため、電圧を与えた状態でも確かめます。

## API と処理の流れ

`analogRead(pin)` は設定された分解能の整数値を返します。`analogReadResolution(bits)` は返す数値の幅を指定します。`analogReadMilliVolts(pin)`（arduino-esp32 と同じ名前）は電圧を返します。ADC の基準は電源電圧で、石が読み取りの直前に内部の基準電圧で測るので、3.3 V を仮定しません。アナログ端子の別名は variant に依存します。

## 改造するときの注意

mV の値には、内部の基準電圧のばらつきと変換器の誤差の分、数 % の幅があります。精密な測定ではありません（測ったことは CH32RV ライブラリの README に書きます）。CH32M030 はデータに内部の基準電圧が無く、電源を 3.3 V と仮定します。
