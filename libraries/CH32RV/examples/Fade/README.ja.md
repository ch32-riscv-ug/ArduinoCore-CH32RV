# Fade

PWM の duty を変えて LED の明るさを連続的に変えます。

## 必要なものと配線

`LED` に指定した PWM 対応端子へ、電流制限抵抗を直列にした LED を接続します。

## 操作と期待する結果

LED が明るくなり、暗くなる動作を繰り返します。明暗が二段階にしか変わらないときは PWM の端子とタイマーの競合を確認します。

## API と処理の流れ

`analogWrite(pin, value)` は設定した分解能に対する duty を指定します。スケッチは0～255で明るさを変えています。DAC の電圧出力ではありません。

## 改造するときの注意

端子変更時は PWM の経路も確認します。同じタイマーを使う tone・Servo 等との関係は [タイマー設計](../../../../docs/timer-design.ja.md) を参照してください。
