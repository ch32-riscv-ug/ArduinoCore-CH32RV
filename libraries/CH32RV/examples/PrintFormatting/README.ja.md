# PrintFormatting

整数・小数・文字列の表示と、生バイト送信の違いを確かめます。

## 必要なものと配線

UART モニタを接続します。書式化処理が必要とするメモリが対象に収まることも確認します。

## 操作と期待する結果

起動時に基数ごとの整数、小数点以下の桁数を変えた値、`dtostrf` の文字列等を表示します。`65` の `print()` と `write()` の違いも確認します。

## API と処理の流れ

整数の `print(value, HEX)` は基数、小数の `print(value, digits)` は小数点以下の表示桁数を指定します。`write()` は値を文字列化しません。`dtostrf()` は呼び出し側の配列へ書き込みます。

## 改造するときの注意

表示桁数と測定の精度は別です。書式化先には符号・小数点・終端を含む十分な容量を確保します。`String` を何度も連結する処理はヒープ使用量も確認します。
