# PulseIn

[English](README.md)

トリガーを出力し、入力パルスの High の継続時間を測ります。

## 必要なものと配線

`TRIGGER` と `ECHO` をパルス応答する機器へ接続し、GND を共通にします。入力電圧が GPIO の許容範囲を超える場合はレベル変換します。UART モニタも用意します。

## 操作と期待する結果

入力パルスがあれば µs 単位の長さを表示し、来なければ期限切れの表示になります。距離表示は超音波センサを想定した換算です。

## API と処理の流れ

`delayMicroseconds()` の単位は µs、`pulseIn(pin, HIGH, timeout)` の戻り値も µs です。戻り値0は有効なパルス幅を得られなかったことを表します。

## 改造するときの注意

`pulseIn()` は結果または期限切れまでスケッチを待たせます。USB 等と併用する場合は待ち時間を小さくし、必要なら割り込みでエッジ時刻を記録する方式を検討します。距離は温度や対象にも依存します。
