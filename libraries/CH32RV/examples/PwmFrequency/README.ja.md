# PwmFrequency

[English](README.md)

dutyを約25%に保ち、3種類のPWM周波数を比較します。オシロスコープやロジックアナライザで変化を確認できます。

## 配線と操作

`PWM_PIN`には基板に出ているPWM対応端子を選び、UARTとの競合を避けます。初期値の`PA1`は例であり、すべての基板のLED端子ではありません。測定器の入力をその端子へつなぎ、GNDを共通にします。適切な電流制限抵抗付きLEDでも試せますが、明るさだけでは周波数の違いを確実に判別できません。

最初は100 Hzを要求します。`n`を送るごとに1000 Hz、5000 Hz、100 Hzへ切り替わります。周期が変わり、Highの割合は約4分の1を保つことを確認します。

## APIと改造時の注意

`analogWriteResolution(8)`はdutyの数値範囲を選びます。`analogWrite(PWM_PIN, 64)`はその約4分の1を指定します。`analogWriteFrequency(pin, Hz)`で周波数を変更した後、もう一度`analogWrite()`して出力へ反映します。

このコアの周波数設定は共有です。pin引数があっても、端子ごとに独立した設定にはなりません。ほかの出力も次に値を書くと共有設定を反映し、同じタイマーのchannelは周期を共有します。隣接するPWM端子で別々の周波数を出せると仮定しないでください。要求値はハードウェアの制約で丸められる場合があります。Servo・tone・タイマーを使うライブラリの所有にも注意します。[TimerResource](../TimerResource/README.ja.md)も参照してください。

波形が出ない場合は、選んだpartのPWM対応とタイマーの所有状況を先に確認します。PWM非対応のGPIOではこの実験を代用できません。

## 実行前の準備

ボードと正確なPart Numberを選び、スケッチの端子を回路図と照合します。ログはハードウェア`Serial`の115200 baud・8N1です。アダプタRXをボードTX、アダプタTXをボードRXへ接続し、GNDを共通にします。I/O電圧を合わせてください。基板のUSB端子だけでこのUARTが見えるとは限りません。

生成された`sketch.yaml`にビルドprofileがあります。ビルド成功は配線や実機動作の確認とは別です。[ビルド規則](../../../../docs/examples-build-rules.ja.md)と[書き込み経路](../../../../docs/upload-routes.ja.md)も参照してください。
