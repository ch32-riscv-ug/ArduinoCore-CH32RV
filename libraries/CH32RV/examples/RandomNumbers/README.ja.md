# RandomNumbers

[English](README.md)

同じ seed による疑似乱数の再現と、seed を変えた場合の違いを確かめます。

## 必要なものと配線

UART モニタを用意します。例は開放したアナログ入力の値も seed に使います。

## 操作と期待する結果

リセットして `seed 1:` の列が再現されること、`d6:` に1～6の値が出ることを確認します。

## API と処理の流れ

`randomSeed(seed)` で生成列の初期条件を設定します。`random(min, max)` の上限 max は含まれないため、六面体は `random(1, 7)` です。

## 改造するときの注意

開放 ADC と時刻を混ぜても、予測困難な乱数が保証されるわけではありません。暗号鍵や認証用の値へ流用しません。再現テストでは固定 seed が便利です。
