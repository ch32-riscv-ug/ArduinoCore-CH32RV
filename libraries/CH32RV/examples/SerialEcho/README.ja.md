# SerialEcho

[English](README.md)

ハードウェア UART で行を受け取り、前後の空白を除いて返信します。

## 必要なものと配線

ボード TX→アダプタ RX、ボード RX←アダプタ TX、GND 同士を接続します。I/O 電圧を合わせ、`RX_PIN` / `TX_PIN` を配線へ合わせます。

## 操作と期待する結果

115200 bps・8N1 で開き、LF を含む行を送ります。起動メッセージのあと、`you said: ...` が返ります。

## API と処理の流れ

`available()` で受信の有無を確認します。`readStringUntil('\n')` は改行またはタイムアウトまで待ち、区切り文字を除いた `String` を返します。`trim()` は先頭・末尾の空白も取り除きます。

## 改造するときの注意

最初の1 byte が届いても行全体が届いたとは限りません。待ちを避けたい処理やバイナリ中継では、`read()` を使い、自分の配列へ少しずつ蓄積します。これは USB CDC の例ではありません。
