# Timing

[English](README.md)

`millis()`・`micros()` と、桁あふれをまたげる時刻の引き算を示します。

## 必要なものと配線

UART モニタを接続します。外部入力は不要です。

## 操作と期待する結果

起動時に短い待ちの計測値、その後に経過秒数が表示されます。計測には呼び出し自体や割り込みの時間も含まれます。

## API と処理の流れ

`now - last >= interval` のように符号なし型の差で経過時間を判断します。`millis()` は ms、`micros()` は µs です。`delayMicroseconds()` は短い待ちに使います。

## 改造するときの注意

`delayMicroseconds()` は忙待ちで、スケッチの処理を進めませんが、それ自体が割り込みを禁止するものではありません。長い待ちや USB 併用では時刻比較で処理を分割します。引き算も、時刻の一周以上を放置した経過を復元できるわけではありません。
