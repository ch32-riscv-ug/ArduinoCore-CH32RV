# ToneMelody

周波数と長さを指定して受動ブザーで音階を鳴らします。

## 必要なものと配線

`BUZZER` に受動ブザーまたは適切な駆動回路を接続します。GPIO の許容電流を超える負荷は直接駆動しません。

## 操作と期待する結果

起動時に音階を一度再生します。再生し直す場合はリセットします。能動ブザーでは指定どおりの音程になりません。

## API と処理の流れ

`tone(pin, frequency, duration)` の周波数は Hz、長さは ms です。呼び出し後もタイマーが鳴動を続け、`noTone(pin)` で停止します。

## 改造するときの注意

例の `delay()` は次の音を始める時刻を待つためです。ほかの入力を扱う場合は時刻管理へ変更します。PWM 等と組み合わせる際は [タイマーの共有](../../../../docs/timer-design.ja.md) を確認します。
