# TouchRead

[English](README.md)

`touchRead()` で TouchKey のパッドを読み、指が触れたら知らせます。ボタンを部品なしで作れます。名前と意味は arduino-esp32 の `touchRead()` と同じで、生の数値を返します。

## 必要なものと配線

`PAD`（既定は `A0`）に、金属のパッドか、短い電線をつなぎます。何もつながなくても動きますが、指で端子に直接触れることになります。UART モニタを用意します。

## 操作と期待する結果

起動して最初の 0.5 秒は触れないでください。その間の値を「触れていないときの値」にします。そのあと指で触れると `touched`、離すと `released` と出ます。

- TouchKey があるのは、今のところ V005〜V007 / M007、X033 / X035、V20x、V30x です。ほかの系列では `touchRead()` が 0 を返し、`No TouchKey on this series or this pin` と出ます。
- 触れたときに値が増えるか減るかは、系列と基板で変わりうるので、この例では離れた幅だけを見ています（実機で指で確かめた向きは、まだ記録していません）。

## API と処理の流れ

- `touchRead(pin)`: アナログ端子の TouchKey の数値（0〜4095）。何もつながっていない端子で、範囲の半分前後になるようにしてあります。
- `touchSetCycles(measure, sleep)`: 充電の時間（ADC のクロック数）を変えます。0 で系列の既定値です。`sleep` は ESP32 の引数で、ここでは使いません。
- 1 回の測定で ADC1 を短く使います。`analogRead()` と同じく、その間は待ちます。

## 改造するときの注意

- パッドが大きいと値が大きく動くので、`THRESHOLD` を上げます。値が上限（4095）や 0 に張り付くときは、`touchSetCycles()` で充電の時間を短く（張り付きが上限のとき）、または長く（0 のとき）します。
- 電源やノイズで値がゆっくり動くときは、触れていない間に `baseline` を少しずつ追わせます。
