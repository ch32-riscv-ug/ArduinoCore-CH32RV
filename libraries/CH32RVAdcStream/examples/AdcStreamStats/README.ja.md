# AdcStreamStats

English: [README.md](README.md)

アナログの端子を 1 本、DMA で連続して取り込み、1 秒ごとに、届いた数、最小・最大・平均、取りこぼしを表示します。

## 必要なものと配線

測りたい電圧を `INPUT_PIN`（既定 `A0`）に入れます（0 V〜電源の電圧）。何もつながなくても動きますが、値は定まりません。115200 bps・8N1 の UART モニタを `RX` / `TX` に。

## 操作と期待する結果

1. 起動すると、1 秒ごとに `ADC_STREAM rate=... samples/s=... halves=... overruns=... min=... max=... mean=...` が出ます。
2. `rate` は `begin()` が測って選んだ段の速さ、`samples/s` は実際に届いた数で、ほぼ同じになります（2026-10-27: CH32V307 で 47,654 と 47,616、CH32X035 で 250,000 と 249,088）。
3. `INPUT_PIN` を GND につなぐと `mean` が 0 付近、電源につなぐと最大付近（12 ビットで 4095）になります。

## 設定と制約

- `WANTED_RATE` は 1 秒あたりの変換の数です。これ以下で一番速い段が選ばれます。一番遅い段より遅くはできないので、系列によっては頼んだより速くなります（CH32X035 は 250,000 より遅くできません）。
- 速いレートでは、`loop()` が 1 回の半分を処理し終わる前に次の半分が来て、`overruns` が増えます（CH32X035 の 250,000 で毎秒 6 回ほど）。処理を軽くするか、半分の長さ `SAMPLES` を大きくします。
- 値は変換器のままで、`analogRead()` の 0〜1023 への換算はかけていません。
