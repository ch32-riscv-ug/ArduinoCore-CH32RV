# DacWaves

[English](README.md)

DAC1 が、64 サンプルの 1 kHz の正弦波（DMA）、DAC 自身の三角波、ノイズを 2 秒ずつ順に出します。

## 必要なものと配線

DAC のある石（V30x、V4x7、H41x）。DAC1 の端子（`CH32RV_DAC1_PIN`、PA4）をオシロスコープに。

## 操作と期待する結果

`Serial` に、波形を変えるたびに `sine: steps/s 64000` のようにタイマーの実際の速さが出ます。
PA4 には、約 0.1〜3.2 V の 1 kHz の正弦波、1024〜2047（約 0.8〜1.65 V）の約 98 Hz の三角波、2048 の上の幅 255 のノイズが出ます。

## API と処理の流れ

`play()` はサンプルの配列を DMA で回して DHR に送り、`triangle()` と `noise()` は DAC の波形の回路を使います。
どれもタイマーの TRGO で 1 段ずつ進むので、出している間 CPU は何もしません。別の波形を呼ぶと、前の波形は止まってから切り替わります。
