# GphaSpeed

[English](README.md)

GPHA（H41x の画像用の DMA）と CPU の速さを比べます。160 × 120 の RGB565 の画面の塗りつぶしと、64 × 64 の ARGB8888 の絵を
RGB565 に変換しながら写す処理を、それぞれで行って時間を `Serial` に出します。

## 必要なものと配線

GPHA のある石（H415 / H416 / H417）。配線は要りません。

## 操作と期待する結果

`fill 160x120 RGB565: GPHA ... us, CPU ... us` と `copy 64x64 ARGB8888 -> RGB565: ...` の 2 行が出ます。H417（V5F 400 MHz）では、塗りつぶしは GPHA 194 µs・CPU 192 µs とほぼ同じで、変換つきのコピーは
GPHA 45 µs・CPU 247 µs でした（2026-11-19）。CPU が速いので、単純な塗りつぶしより、変換や合成で差が出ます。

## API と処理の流れ

`Surface` がバッファ（画素、形式、1 行の画素数）で、`fill()`・`copy()`・`blend()` が四角の範囲をハードで処理します。
LCD（LTDC）のフレームバッファや、SPI の LCD に送る前の画面の組み立てに使えます。
