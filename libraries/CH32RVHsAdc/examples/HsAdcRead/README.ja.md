# HsAdcRead

高速 ADC で1回ずつ変換し、カウント値と換算電圧を UART に表示します。

## 必要なものと配線

対象ボードの PC0 と GND へ、入力範囲内の信号を接続します。このスケッチは VIO18 を3.3 Vに変更します。VIO18 につながるすべての部品がその電圧に対応することを先に確認します。

## 操作と期待する結果

UART で `HSADC at ... samples/s` と PC0 の測定値を確認します。初期化に失敗した場合は入力端子と対象型番を確認します。

## API と処理の流れ

`hsadc.begin(pin, samplesPerSecond)` で開始し、実際の設定は `sampleRate()` で確認します。`read()` は単発変換の値を返します。

## 改造するときの注意

入力の上限は端子自身の電源に依存します。電圧換算も基準電圧に依存するため、生値と合わせて確認します。連続取得中の `read()` との併用を避け、詳細は [ライブラリ README](../../README.ja.md) を参照します。
