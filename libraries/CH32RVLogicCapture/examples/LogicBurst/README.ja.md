# LogicBurst

GPIO ポートを一度に取り込み、PWM の周期が何サンプル分かを調べます。

## 必要なものと配線

対象ボードと UART モニタを用意します。例は PE3 で PWM を生成し、そのポートの入力レジスタから読むので外付けの信号源は不要です。

## 操作と期待する結果

取り込みごとに推定サンプルレート・立ち上がり数・1周期のサンプル数が出ます。PWM 周波数とサンプルレートから予想する周期と比較します。

## API と処理の流れ

`logic.begin(port, rate)` で対象を指定し、`captureBurst(buffer, samples)` で一度取り込みます。戻り値は実行時のレート、0なら失敗です。`buf[i]` の bit n はポートの端子 n に対応します。

## 改造するときの注意

burst はタイマーで等間隔を作る方式とは異なり、バスの競合でも間隔が変わります。実行中の割り込み禁止がほかの処理へ与える影響も考えます。外部信号をつなぐ場合は端子の電源領域と許容電圧を確認します。
