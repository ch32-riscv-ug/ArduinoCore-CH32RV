# LogicPulseDecode

[English](README.md)

GPIO のポートを連続して取り込み、デジタル信号の周波数とデューティ比を測ります。取り込みは DMA が行い、スケッチは埋まった半分ごとにエッジを探すだけです。次の半分が埋まっている間にデータを処理する書き方の例です。

## 操作

出荷のまま（`SELF_TEST 1`）だと、取り込みと別のタイマーで PWM を出せる最初の端子に 1 kHz・25 % の PWM を出し、その端子自身を測ります。配線は要りません。毎秒 `1000.0 Hz, duty 25.0 %, period 100-100 samples` と出ます。`TEST_HZ` と `TEST_DUTY` を変えると、結果もそれに合わせて変わります。

自分の信号を測るときは `SELF_TEST 0` にし、起動時に表示される端子（`Measuring PA1 ...`）へ入れます。端子の電圧の範囲を守り、GND を共通にしてください。線が止まっていると `No edges: held high` / `held low` と出ます。

## API と改造時の注意

- `begin(port, rate)` でポート全体（16 本）を取り、`startContinuous(buf, samples)` で前半と後半を交互に埋めます。`readBuffer()` は埋まった半分を返します。その半分は、DMA が戻ってくるまで有効です。スケッチが遅くて失った半分は `overruns()` に数え、出力にもそう出します。
- `RATE` = 100 kHz では 1 サンプルが 10 us です。周期は 1 サンプル単位でわかるので、1 kHz は 100 サンプルと読めます。速い信号では `RATE` を上げます（`maxContinuousRate()` まで）。1 周期がバッファの半分より長い遅い信号は、1 回の表示の中で 1 周期にもなりません。
- エッジと数は半分から次の半分へ引き継ぐので、半分をまたぐ周期も測れます。
- V00x / X035 では、取り込みが TIM2 を使います。TIM2 は一部の端子の PWM と `tone()` にも使われるので、ここでは別のタイマーの端子を選んでいます。

## 実行前の準備

出力はハードウェア `Serial` の 115200 baud・8N1 です。アダプタ RX をボード TX、アダプタ TX をボード RX へ接続し、GND を共通にします。生成された `sketch.yaml` にビルド profile があります。[ビルド規則](../../../../docs/examples-build-rules.ja.md)と[書き込み経路](../../../../docs/upload-routes.ja.md)も参照してください。
