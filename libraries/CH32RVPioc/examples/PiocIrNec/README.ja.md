# PiocIrNec

[English](README.md)

PIOC で NEC 方式の赤外線リモコンのフレームを送ります。`ir_nec.S` が IO0 の赤外線 LED を 38 kHz の搬送波（High 1/3）で光らせます。
1 秒ごとに、アドレス 0x00・コマンド 0x45 を送ります。

## 必要なものと配線

PIOC のある石（X035 / X033、V205、H41x）と赤外線 LED。IO0 の端子（スケッチの `IO0_PIN`。CH32H417 は PA0、CH32X035 は PC7、
CH32V205 は PB10）から、トランジスタ（NPN か N チャネルの MOSFET）で LED を駆動します。端子から LED を直接光らせるのは、
電流が足りず距離が出ません。

## 操作と期待する結果

テレビなど NEC 方式の受信器に向けると、そのコマンドとして受け取ります。ロジックアナライザでは、9 ms のリーダー、4.5 ms の間、
32 ビット（アドレス、その反転、コマンド、その反転。LSB から）、終わりのマークが見えます。

## API と処理の流れ

- d0〜d3 がフレームの 4 バイト（アドレスが 0xFF より上なら、拡張の 16 ビットのアドレスの上位を d1 に）。
- d4 / d5 が搬送波の High の部分、d6 / d7 が Low の部分の待ちの回数です。1 周期は (3 × d4 + 770 × d5) + (3 × d6 + 770 × d7) + 25
  サイクルで、`CH32RVPioc::clockHz()` から計算します。
- マークとスペースは搬送波の周期の数で数えます（同じルーチンで、出力するかどうかだけが違うので、どちらも同じ長さ）。
- PIOC は一度 `begin()` したら走らせたままにします（`begin()` はリセットなので、その間 IO0 が浮きます）。

H417・X035（48 MHz）・V205 で、WireSkein の `ir` が通っています（2026-11-19、pioc::test_pioc_ir_nec。普通のアドレスと
拡張のアドレスのフレーム、コマンドの反転、搬送波 37.99〜38.00 kHz、マークとスペースの長さ）。
