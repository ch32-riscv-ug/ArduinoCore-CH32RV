# PiocOneWire

[English](README.md)

PIOC で 1-Wire のマスターを作ります。`onewire.S` が IO0 にリセット・書き込み・読み出しのスロットをマイクロ秒の時間で作るので、
メインのコアの割り込みでスロットが延びません。DS18B20 の温度を 1 秒ごとに読んで Serial に出します。

## 必要なものと配線

PIOC のある石（X035 / X033、V205、H41x）と DS18B20（ほかの 1-Wire のデバイスでも、コマンドを変えれば使えます）。DS18B20 の
DQ を IO0 の端子（スケッチの `IO0_PIN`。CH32H417 は PA0、CH32X035 は PC7、CH32V205 は PB10）に、DQ と 3.3 V の間に 4.7 kΩ の
プルアップ、VDD は 3.3 V、GND は共通に（寄生電源の接続には対応していません）。

## 操作と期待する結果

Serial を 115200 bps で開くと、`23.5625 C` のように 1 秒ごとに温度が出ます。デバイスがいなければ
`no device (no presence pulse)`、スクラッチパッドの CRC が合わなければ `CRC error` です。

## API と処理の流れ

- 端子は `setOpenDrain(0)` で開放ドレインにします。出力の 0 で線を Low に引き、1 で放します（プルアップが High にする）。
  `begin()` のままのプッシュプルでは、線を放せません。
- 1 µs は PIOC の 3 × d1 + 4 サイクルで、d1 は `CH32RVPioc::clockHz()` から計算します。
- コマンドの値で動きが決まります。1 はリセット（500 µs Low、放して 70 µs 後に線を見る。cmd.out は存在のパルスがあれば 0、
  無ければ 1）、2 は d8〜d31 の d0 バイトを書く、3 は d0 バイトを読む（どちらも LSB から、24 バイトずつ）。
- 1 の書き込みは 6 µs Low・64 µs 放す、0 は 60 µs Low・10 µs 放す。読み出しは 6 µs Low、放して 9 µs 後に線を見て、55 µs 待つ。
- スケッチは Skip ROM で 1 個だけのバスを前提にしています。複数のデバイスには ROM の検索（Search ROM）を足します。

H417・X035・V205 で、デバイスの無い線（プローブのプルアップ）を WireSkein の `onewire`（標準の速さ）で判定して通っています
（2026-11-20、pioc::test_pioc_onewire。リセットが存在のパルス無し、書いたバイトと読み出しの ff、スロットと Low の長さが規格の
範囲）。測った長さはリセット 500 µs、0 の Low 60.5 µs、1 の Low 6.5 µs、スロット 70 µs（V205）。実際の DS18B20 ではまだ
試していません。
