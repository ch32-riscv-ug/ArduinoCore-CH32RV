# PiocUartRx

[English](README.md)

PIOC でシリアルの受信をもう 1 つ増やします。`uart_rx.S` が IO0 で 8N1 のバイトを受けて共有レジスタに溜め、スケッチが 8 バイトずつ
`Serial` に出します（2 秒来なければ、来た分だけ）。

## 必要なものと配線

PIOC のある石（X035 / X033、V205、H41x）。送る側の TX（USB シリアル変換器など、3.3 V）を IO0 の端子（スケッチの `IO0_PIN`。
CH32H417 は PA0、CH32X035 は PC7、CH32V205 は PB10）に。GND も共通に。速さはスケッチの `BAUD`（115200）。

## 操作と期待する結果

変換器から 8 文字送るごとに、`PIOC got: ` に続いてその 8 文字が出ます。

## API と処理の流れ

- d0 が受けるバイト数（1〜24）、d1 / d2 が 1 ビットの待ち、d3 / d4 が開始ビットの立ち下がりから bit 0 の中央までの待ちです。
  1 ビットは PIOC の 3 × d1 + 770 × d2 + 11 サイクルで、`CH32RVPioc::clockHz()` と速さから計算します。
- プログラムは、線が High になるのを待ってから開始ビットを待ち、各ビットの中央で IO0 を 1 サイクル（`BG2F`）で読みます。
  受けたバイトは d8〜d31 に入り、d7 がその数です。d0 個そろうと `waitDone()` が 0 を返します。
- そろう前に時間切れになったら d7 と d8〜を読み、`begin()` し直して待ちを止めます。
- 24 バイトを受けている間はホストが読まないので、続けて受けるには間（相手が送らない時間）が要ります。

H417・X035（48 MHz）・V205 で、プローブの UART が送った 24 バイトを 9600・115200・1M bps で 1 バイトも違えずに受けています
（2026-11-19、pioc::test_pioc_uart_rx）。
