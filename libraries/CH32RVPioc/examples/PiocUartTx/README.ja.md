# PiocUartTx

[English](README.md)

PIOC でシリアルの送信をもう 1 つ増やします。`uart_tx.S` が IO0 に 8N1 で文字列を送り、その間メインのコアは別の仕事を続けられます。
0.5 秒ごとに `PIOC says hello, millis() = ...` を 115200 bps で送ります。

## 必要なものと配線

PIOC のある石（X035 / X033、V205、H41x）。IO0 の端子（スケッチの `IO0_PIN`。CH32H417 は PA0、CH32X035 は PC7、CH32V205 は PB10）を、
USB シリアル変換器の RX に。GND も共通に。

## 操作と期待する結果

シリアルのターミナルを 115200 bps で開くと、0.5 秒ごとに 1 行ずつ出ます。

## API と処理の流れ

- 送るバイトは共有レジスタの d8〜d31 で、24 バイトずつ渡します。d0 がそのバイト数、d1 / d2 が 1 ビットの待ちの回数です。
  1 ビットは PIOC の 3 × d1 + 770 × d2 + 11 サイクルで、`CH32RVPioc::clockHz()` と速さから計算します。
- `command()` で送り始め、`waitDone()` で最後のストップビットまで待ちます。
- `loadSram()` は使いません。SRAM に書くと PIOC がリセットされ、その間 IO0 が浮いて、アイドルの High が保てないためです。
  PIOC は一度 `begin()` したら走らせたままにします。
- 1 ビットは最短 14 サイクル（48 MHz で約 3.4 Mbps まで）、最長は約 20 万サイクル（48 MHz で約 240 bps まで）。

H417・X035（48 MHz）・V205 で、9600・115200・1M bps の送信を WireSkein の `uart` で判定して通っています
（2026-11-19、pioc::test_pioc_uart_tx。バイト列・8N1・フレームの誤り無し）。
