# PiocWs2812

[English](README.md)

PIOC で WS2812（NeoPixel）の LED を光らせます。`ws2812.S` のプログラムが 1 フレームを送る間、メインのコアは割込みを止めずに
ほかの仕事を続けられます（コアの `rgbLedWrite()` はソフトで送るので、送っている間は割込みが止まります）。30 個の LED に虹を流します。

## 必要なものと配線

PIOC のある石（X035 / X033、V205、H41x）と WS2812 の LED（帯でも 1 個でも）。IO0 の端子（スケッチの `IO0_PIN`。CH32H417 は PA0、
CH32X035 は PC7、CH32V205 は PB10）を LED の DIN に。LED の電源と GND も共通に。5 V の LED に 3.3 V の信号で足りないときは、レベル変換を入れます。

## 操作と期待する結果

LED に、少しずつ動く虹が出ます（明るさは 1/8 に抑えています）。

## API と処理の流れ

- 色のデータ（LED ごとに G、R、B の 3 バイト）は、`loadSram(0x400, pixels, n)` で PIOC のプログラム SRAM の 0x400 に写します。
  PIOC は走り直すので、d0〜d5 はそのあとで書きます。
- d0 / d1 が送るバイト数、d2〜d5 が 3 サイクルのループの回数です。0 の High（350 ns）、1 の High（800 ns）、1 ビット（1.25 µs）、各バイトの最後のビットの Low（次のバイトの用意を含めて同じ周期）に
  なるよう、`CH32RVPioc::clockHz()` から計算します。プログラムの中のサイクル数は `ws2812.S` の先頭に書いてあります。
- `command()` で送り始め、`waitDone()` で終わりを待ちます。終わったら 50 µs 以上 Low のままにするとラッチされます（ここでは 300 µs）。
- 送れるのは SRAM の 0x400〜0xFFF の 3072 バイト（1024 個の LED）までです。

H417・X035（48 MHz）・V205 で、10 個と 100 個の LED のフレームを WireSkein の `rgb_led` で判定して通っています（2026-11-19、pioc::test_pioc_ws2812。
T0H・T1H・ビットの周期とバイト列）。
