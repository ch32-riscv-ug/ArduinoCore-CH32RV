# RotaryEncoder

[English](README.md)

タイマーのエンコーダモードで、直交のロータリーエンコーダを数えます。位置が変わったら表示します。数えるのはタイマーで、`getCount()` は 64 ビットの数を返します。

## 操作

出荷のまま（`SELF_TEST 1`）だと、エンコーダの 2 本の端子を自分で動かして、仮のエンコーダを回します。配線は要りません。1 秒ごとに、40 ステップ進めるのと 25 戻すのを交互に行うので、`count 40`、`count 15`、`count 55`、`count 30` … と出ます。

本物のエンコーダを使うときは `SELF_TEST 0` にし、起動時に表示される 2 本の端子（`Encoder A PA6, B PA7`）へ A と B を、共通の端子を GND へつなぎます。端子はプルアップするので、抵抗は要りません。回すと数が変わります。逆に増えるときは A と B を入れ替えます。

## API と改造時の注意

- `attachFullQuad()` は 1 周期（クリック 1 つのことが多い）で 4 カウントです。1 クリックで 1 つ増やしたいときは `attachSingleEdge()` を使うか、4 で割ります。
- `setFilter(F_CPU / 250000)` は、約 4 µs より短いパルスを無視します。チャタリングが多いエンコーダでは、値を大きくします（最大 1024 サイクル）。
- 端子は、1 つのタイマーのチャネル 1 と 2 から自動で選びます。自分で決めるときは、その系列の同じタイマーのチャネル 1 と 2 を `pinA` / `pinB` に入れます（[ライブラリの README](../../README.ja.md)）。

## 実行前の準備

出力はハードウェア `Serial` の 115200 baud・8N1 です。アダプタ RX をボード TX、アダプタ TX をボード RX へ接続し、GND を共通にします。生成された `sketch.yaml` にビルド profile があります。[ビルド規則](../../../../docs/examples-build-rules.ja.md)と[書き込み経路](../../../../docs/upload-routes.ja.md)も参照してください。
