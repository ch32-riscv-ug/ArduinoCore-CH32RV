# HalfBridge

[English](README.md)

高機能タイマーの 1 つのチャネルで、半ブリッジの上下を動かします（`CH32RVComplementaryPwm`）。CHx が上側、CHxN が下側（CHx の反転）で、切り替えの前後に両方オフのデッドタイムを入れ、ブレーキ入力でハードが両方をオフにします。

## 配線

**波形をロジックアナライザかオシロスコープで確かめるまで、パワー段をつながないでください。** 端子はスケッチが自分で選び、起動時に表示します（`High side PA8, low side PB13, dead time 500 ns`）。両方を見ると、同時に High になることはなく、一方が Low になってからもう一方が High になるまでの間がデッドタイムです。チップに同じ経路のブレーキ入力があれば、それも表示します（`Break input PB12`）。GND につなぐと、両方の出力が即座に Low になります。

## 手順と期待する結果

20 kHz で duty がゆっくり上下します。ブレーキ入力を GND に落とすと `Break: both sides off` と出て、離すと `resume()` で出力が戻ります（`Resumed`）。

## API と改造時の注意

- `PWM_HZ` と `DEAD_NS` が周波数とデッドタイムです。`deadTime()` は実際に設定した値です。タイマーのデッドタイムの欄はクロックの刻みで、長いほど粗くなります（最大 1008 クロック）。
- `write(duty)` はここでは 0〜256 です（`begin(..., 8)` で 8 ビット、256 が 100 %）。
- 両方の出力は High が有効で、ブレーキと `end()` で Low になります。別の極性のゲートドライバには、インバータが要ります。

## 実行前の準備

出力はハードウェア `Serial` の 115200 baud・8N1 です。生成された `sketch.yaml` にビルド profile があります。[ビルド規則](../../../../docs/examples-build-rules.ja.md)と[書き込み経路](../../../../docs/upload-routes.ja.md)も参照してください。
