# Gamepad

English: [README.md](README.md)

6軸、ハット、ボタン bitmap を持つ HID ゲームパッドのテスト入力を送ります。

## 必要なものと配線

PC のゲームコントローラ状態表示アプリと UART モニタ。外付けジョイスティックは不要です。

## 操作と期待する結果

1. 約500 ms ごとに軸値とハット、ボタンが変わります。
2. UART の `GAMEPAD_TX` と PC の状態を照合します。
3. ボタンは先頭8個が順に有効になり、軸は約 -127～127 のテスト値を循環します。

## 設定と制約

report は32ボタンを表せますが、この例が循環するのは8個です。アナログ入力へ変更する場合は、ADC の分解能と中心値を軸の範囲へ変換します。
