# Mouse

English: [README.md](README.md)

相対移動、ホイール、左ボタンを順に送る USB マウスです。物理スイッチやセンサは使いません。

## 必要なものと配線

PC と UART モニタ。接続後に自動でポインタ移動とクリックを行います。テスト用の画面を開きます。

## 操作と期待する結果

1. 約1秒ごとに右30、下30、左30、上30の相対移動が起きます。
2. 続いてホイール +1、左ボタンの約50 ms の押下・解放が起きます。
3. この6段階が繰り返されます。送信失敗は `MOUSE_FAILED` として UART に出ます。

## 設定と制約

`move()` の値は画面の絶対座標ではありません。PC のポインタ加速設定により実際の移動ピクセル数は変わります。物理入力へ置き換える際は、押した状態と離した状態の両方を送ります。

## API の使い方と改造のポイント

| API | この例での使い方 |
|---|---|
| `move(x, y)` | 符号付きの相対移動を送ります。移動量が引数の型の範囲を超える場合は複数回に分けます。 |
| `wheel(amount)` | ホイールの相対量を送ります。スクロール量や向きの見え方はホスト設定にも依存します。 |
| `press(button)` / `release(button)` | 定数で指定したボタンを押し、離します。両方の操作が必要です。 |
| `click(button)` | 押下と解放をまとめて送る場合に使います。 |

センサからの差分へ改造するなら、送信成功まで未送信の移動量を残しておきます。型の範囲を超えた値をそのまま
キャストすると、向きが逆転することがあります。押下状態も含めて、失敗した report をどう再送するかを決めます。

この例の `delay(50)` は押している時間を見せるためのものです。ほかの入力も同時に処理したい場合は、
`millis()` で解放予定を管理して `loop()` を止めない形へ変更します。
