# MdnsWebServer

[English](README.md)

ポート 80 の小さな Web サーバーです。mDNS で名前を公開するので、PC からアドレスを知らなくても `http://ch32rv.local/` で開けます。ページには起動からの時間と表示回数が出ます。ほかのパスには 404 を返します。

## 操作

ログに `http://ch32rv.local/  (192.168.x.y)` と出ます。同じネットワークのブラウザで開きます（macOS、iOS、Windows 10 以降、Avahi の入った Linux は `.local` の名前を引けます）。アドレスで開いても同じです。リクエストのたびに、クライアントのアドレスとパスを表示します。Bonjour / Avahi のブラウザには `_http._tcp` のサービスとして出ます。

## API と改造時の注意

`MDNS.begin(name)` はアドレスが決まってから呼びます。`MDNS.addService("http", "tcp", 80)` で、サーバーを見つけられるようにします。名前は、ネットワークの中で重ならないものにしてください。リクエストの読み取りは `REQUEST_TIMEOUT_MS` で打ち切るので、つないだだけで何も送らないクライアントがサーバーを止めることはありません。HTTP/1.0 で答えて、ページごとに接続を閉じます。同時に扱うクライアントは 1 台です。

## 実行前の準備

Ethernet の MAC を持つボードを選び（生成された profile は CH32V307。V208、V317、V407 / V467、H415〜H417 も同じ書き方で動きます）、RJ45 を DHCP サーバーのあるネットワークにつなぎます。ログはハードウェア `Serial` の 115200 baud・8N1 です。アダプタ RX をボード TX、アダプタ TX をボード RX へ接続し、GND を共通にします。基板の USB 端子にはこの UART は出ていません。

通信の処理は `delay()` の中と各 `loop()` の後で進みます。スケッチが poll の関数を呼ぶ必要はありません。ビルドが通っても、ケーブルやネットワークの確認にはなりません。[ビルド規則](../../../../docs/examples-build-rules.ja.md)と[書き込み経路](../../../../docs/upload-routes.ja.md)も参照してください。
