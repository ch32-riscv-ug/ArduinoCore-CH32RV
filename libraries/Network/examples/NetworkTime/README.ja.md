# NetworkTime

[English](README.md)

NTP サーバーで時計を合わせ、毎秒、現地時刻を表示します。最初の応答が来るまでは、1970 年の日付を出さずに、まだ合っていないと表示します。

## 操作

アドレスを得たあと、少しの間 `Time not set yet` が出て、そのあと `2026-10-27 13:40:02 JST` のような行が出ます。`TZ_INFO` を自分のタイムゾーンに変えてください（`UTC0`、`CET-1CEST,M3.5.0,M10.5.0/3` など）。NTP サーバーに届かないと、メッセージが出たままになります。

## API と改造時の注意

`configTzTime(tz, server)`（または `configTime(時差, 夏時間, server)`）は SNTP を始めて、すぐ戻ります。時計は最初の応答で合い、そのあとも 1 時間ごとに合わせ直します。`getLocalTime(&tm, 0)` は待たずに、合うまでは false を返します。時間を渡すと、その ms だけ待ちます。合ったあとは、`time()`、`localtime_r()`、`strftime()` が普通に使えます。合わせる間は `millis()` で時計を進めていて、リセットすると時刻は失われます。

## 実行前の準備

Ethernet の MAC を持つボードを選び（生成された profile は CH32V307。V208、V317、V407 / V467、H415〜H417 も同じ書き方で動きます）、RJ45 を DHCP サーバーのあるネットワークにつなぎます。ログはハードウェア `Serial` の 115200 baud・8N1 です。アダプタ RX をボード TX、アダプタ TX をボード RX へ接続し、GND を共通にします。基板の USB 端子にはこの UART は出ていません。

通信の処理は `delay()` の中と各 `loop()` の後で進みます。スケッチが poll の関数を呼ぶ必要はありません。ビルドが通っても、ケーブルやネットワークの確認にはなりません。[ビルド規則](../../../../docs/examples-build-rules.ja.md)と[書き込み経路](../../../../docs/upload-routes.ja.md)も参照してください。
