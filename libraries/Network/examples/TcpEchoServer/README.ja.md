# TcpEchoServer

[English](README.md)

ポート 7 の TCP サーバーです。クライアントが送ったものを、そのまま返します（同時に 1 台）。クライアントの受け付け、届いた分の読み取り、送信バッファが一部しか受け取らないときの書き込み、切断の検出を示します。

## 操作

`Echo server on 192.168.x.y:7` とアドレスが出ます。同じネットワークの PC から `nc 192.168.x.y 7` を実行して行を打つと、そのまま返ってきます。ボードはクライアントのアドレスを表示し、切断すると `Closed after N bytes` を表示します。60 秒間何も送らないクライアントは切ります。2 台目は、1 台目が終わるまで待たされます。

## API と改造時の注意

TCP はバイトの流れです。`read()` は今までに届いた分を返します。相手の 1 回の `write()` が何回かの read に分かれることも、何回かの write が 1 回にまとまることもあります。メッセージの区切り（行末や長さ）は、自分で上に載せます。`write()` はスタックが受け取った量を返すので、残りは送り直します。切断したクライアントは偽になるので、切断の表示を 1 回にするため、スケッチは自分でフラグを持っています。

## 実行前の準備

Ethernet の MAC を持つボードを選び（生成された profile は CH32V307。V208、V317、V407 / V467、H415〜H417 も同じ書き方で動きます）、RJ45 を DHCP サーバーのあるネットワークにつなぎます。ログはハードウェア `Serial` の 115200 baud・8N1 です。アダプタ RX をボード TX、アダプタ TX をボード RX へ接続し、GND を共通にします。基板の USB 端子にはこの UART は出ていません。

通信の処理は `delay()` の中と各 `loop()` の後で進みます。スケッチが poll の関数を呼ぶ必要はありません。ビルドが通っても、ケーブルやネットワークの確認にはなりません。[ビルド規則](../../../../docs/examples-build-rules.ja.md)と[書き込み経路](../../../../docs/upload-routes.ja.md)も参照してください。
