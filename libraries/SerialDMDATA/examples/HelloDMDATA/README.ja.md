# HelloDMDATA

[English](README.md)

デバッグレジスタ経由で入力を受け、英小文字を大文字にして返します。

## 必要なものと配線

対応プローブとデバッグ接続を用意します。UART の追加配線は不要です。

## 操作と期待する結果

対応するホスト端末（スケッチでは `minichlink -T`）を開き、入力した文字が大文字で返ることを確認します。経過秒数も表示されます。

## API と処理の流れ

`available()` でデバッグレジスタの受信を取り込み、`read()` と `write()` で1 byteずつ中継します。baud は互換用の引数です。

## 改造するときの注意

受信と送信で共有するレジスタを使うため、周期表示だけにせず受信をこまめに読みます。同じデバッグレジスタを使う SDI / DMSeq と混ぜず、ホスト側も DMDATA の方式を選びます。
