# RttEcho

RTT の双方向通信で、入力を大文字へ変換しながら LED の点滅を続けます。

## 必要なものと配線

対応プローブとデバッグ接続を用意します。LED を使う場合は、基板に合う `LED_BUILTIN` の定義が必要です。

## 操作と期待する結果

RTT モニタから文字列を送り、大文字の返信を確認します。LED 定義がない構成でもエコーの確認はできます。

## API と処理の流れ

`available()` のある分だけ `read()` し、`write()` で返します。LED は `millis()` で状態を決め、受信を待ち続けないようにしています。

## 改造するときの注意

RTT のモニタを入力も送信できる設定で開きます。ポーリングで待たない形にしていても送信バッファには限りがあるため、連続入力を扱う用途では送信結果も確認します。
