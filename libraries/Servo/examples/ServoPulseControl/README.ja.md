# ServoPulseControl

[English](README.md)

シリアルから、マイクロ秒のパルス幅か角度でサーボを動かします。切り離しと再接続もできます。[Sweep](../Sweep/README.ja.md) の次の段階として、サーボが受け付けるパルスの範囲と、切り離すと何が起きるかを示します。

## 配線

サーボの信号線を `SERVO_PIN`（PA1）へつなぎます。サーボの電源は別に用意し（多くは 4.8〜6 V）、GND をボードと共通にします。ボードの 3V3 から給電しないでください。多くのサーボは 3.3 V の信号で動きますが、手持ちのものを確かめてください。

## 操作

コンソールを 115200 baud、行末 CR か LF で開きます。起動するとサーボは中央へ行き、`1500 us = 90 deg` と出ます。続けて:

- `1200` — 1200 us のパルス（`1200 us = 36 deg`）。`MIN_US`〜`MAX_US` の外は範囲に収めます（`3000` は 2000 になります）。
- `a180` — 角度。0 度と 180 度が `MIN_US` と `MAX_US` です。
- `d` — 切り離し。パルスが止まり、端子は Low のままになるので、サーボは位置を保たなくなります。
- `r` — 再接続。パルスは中央から再開します。

## API と改造時の注意

`attach(pin, min, max)` でパルスの範囲を決めます。`MIN_US` / `MAX_US` はサーボの資料に合わせてください。多くは 1000〜2000 us、500〜2500 us のものもあります。端を越えて押し付けると、ギアに無理がかかります。`writeMicroseconds()` が細かく指定する形で、`write()` は角度をこの範囲に割り当てます。パルスはタイマーが 20 ms ごとに出し続けるので、`loop()` はコンソールを読むことに使えます。系列に空いたタイマーが無いときは、`attach()` が `INVALID_SERVO` を返します。

CH32V103 で、同じ端子を CH32RVLogicCapture で測りました（2026-10-28）。1000、1500、2000、2400 us はその幅で出て、544 us は 550 us でした（10 us ごとの取り込み）。

## 実行前の準備

ログはハードウェア `Serial` の 115200 baud・8N1 です。アダプタ RX をボード TX、アダプタ TX をボード RX へ接続し、GND を共通にします。生成された `sketch.yaml` にビルド profile があります。[ビルド規則](../../../../docs/examples-build-rules.ja.md)と[書き込み経路](../../../../docs/upload-routes.ja.md)も参照してください。
