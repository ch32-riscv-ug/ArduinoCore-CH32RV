# Sweep

[English](README.md)

サーボへ角度を指定し、端から端へ往復させます。

## 必要なものと配線

信号線を `SERVO_PIN`、電源をサーボに適した外部電源へ接続し、GND を MCU と共通にします。基板の I/O 電源からモーターの電流を取らないようにします。

## 操作と期待する結果

往復動作を確認します。初期化に失敗すると UART へ表示されます。機構の端にぶつかる場合は可動範囲を小さくします。

## API と処理の流れ

`servo.attach(pin)` の戻り値を `INVALID_SERVO` と比較して確認します。`write(angle)` は目標角を指示するもので、到達の検出や待機は行いません。

## 改造するときの注意

例の待ち時間は動く余裕を与えるものです。実際の動作範囲と必要電流を確認し、PWM 等とのタイマー共有は [タイマー設計](../../../../docs/timer-design.ja.md) を参照します。
