# I2COledSH1106

[English](README.md)

SH1106（128×64 の OLED、I2C）に文字とカウンタを出します。表示のライブラリは使わず、Wire だけで動かします。

## 必要なものと配線

SH1106 の I2C のモジュール（1.3 インチのものが多い）を、VCC を 3.3 V、GND、SDA と SCL をスケッチの端子へつなぎます。多くの
モジュールはプルアップ（4.7〜10 kΩ）を載せています。無ければ SDA と SCL に付けます。アドレスはたいてい 0x3C で、モジュールの
アドレスのジャンパーを変えると 0x3D です（スケッチの `OLED_ADDR`）。

## 操作と期待する結果

起動すると、1 行目に `Hello, SH1106!`、2 行目に `CH32RV Arduino`、3 行目に使っている端子（`SDA PC18  SCL PC19` のように名前で）
が出て、4 行目の `uptime` が 0.5 秒ごとに進みます。何も出ないときは、配線・電源・アドレスを確かめ、I2CScanner で 0x3C か 0x3D
が見えるかを調べます。

## API と処理の流れ

SH1106 は、先頭の制御バイトでコマンド（0x00）か表示データ（0x40）かを区別します。初期化のコマンドの列を送ってから、ページ
（8 ドットの行）と列を指定して、5×7 の字形を 1 文字 6 ドットで書きます。画面のバッファ（1 KB）は持たないので、RAM 2 KB の
V003 にも入ります。SH1106 の RAM は 132 列あり、128 ドットの画面は 2 列目から始まります（`COLUMN_OFFSET`）。データは Wire の
32 バイトのバッファに収まるよう、16 バイトずつ送ります。

## 改造するときの注意

- SSD1306 の 128×64 のモジュールは、ほぼ同じコマンドで動きますが、`COLUMN_OFFSET` は 0 です（DC-DC の 0xAD 0x8B の代わりに
  0x8D 0x14 を送ります）。
- 画面が上下逆なら、初期化の 0xA1 / 0xC8 を 0xA0 / 0xC0 にします。
- **WeAct CH32X035（F8U6）では**、I2C がデバッグの端子 PC18 / PC19（か USB の端子 PC16 / PC17）にしか出ていません。PC18 /
  PC19 を使うときは、スケッチのコメントの端子に切り替え、`USE_DEBUG_PADS` を 1 にします。`CH32RV.releaseDebugPins()` で
  デバッガーが端子を手放し、次のリセットまで WCH-Link や OEP の probe から接続できません。スケッチは USB のデバイス（`SerialUSB`）
  を動かすので、次の書き込みは基板の USB（`ch32rv-app://` の口かシリアルポート）でできます。
