ArduinoCore-CH32

WCH CH32 RISC-V マイコン向けの、コミュニティ管理の Arduino コア
A community-maintained Arduino core for WCH CH32 RISC-V microcontrollers

β版です（0.0.x）。版の間で破壊的変更が入ることがあります。
This is a beta. A version may still break what the previous one did.

インストール / Install

  1. Arduino IDE の「ファイル → 基本設定 → 追加のボードマネージャのURL」に次を足す
    Add this under File → Preferences → Additional boards manager URLs
https://ch32-riscv-ug.github.io/ArduinoCore-CH32/package_ch32-riscv-ug_index.json
  1. ボードマネージャで「CH32 RISC-V」を入れる（toolchain と書き込みツール ch32rv も一緒に入る）
    Install "CH32 RISC-V" from the Boards Manager (the toolchain and the ch32rv uploader come with it)
  2. port で WCH-Link の serial port か wchlink://…、OEP の probe なら oep://… を選び、書き込む
    Pick the port - a WCH-Link's serial port or wchlink://…, an OEP probe's oep://… - and upload

arduino-cli:

arduino-cli core install ch32-riscv-ug:ch32v \
  --additional-urls https://ch32-riscv-ug.github.io/ArduinoCore-CH32/package_ch32-riscv-ug_index.json
